# Смена IP или домена

Что делать, когда публичный IP сервера или его домен меняется. Базе данных
адрес безразличен — меняться должны только DNS, TLS-сертификат и закладки на ТВ.

## Поменялся только IP, домен тот же

Типичный случай: провайдер выдал новый IP или вы переехали на другую машину под
тем же именем DuckDNS.

1. Направьте DNS-запись на новый IP. Для DuckDNS это одно поле на сайте —
   изменение применяется за минуту-две.
2. Откройте порты 80 и 443 на новом хосте (файрвол и, если есть, security group
   облачного провайдера).
3. Если сервер переехал на другую машину, скопируйте проект и базу — см.
   [Переезд на новый сервер](moving-to-a-new-server.ru.md).
4. Проверьте: `curl https://<ваш-домен>/msx/start.json` должен отвечать.

Сертификат перевыпускать **не нужно** — он привязан к доменному имени, а не к
IP. `./kptv.sh restart` не обязателен, но и не повредит.

## Поменялся домен

1. Перевыпустите сертификат на новое имя — та же команда certbot, что в README
   (Установка, шаг 3), только с новым `-d`. Сохраните фиксированный
   `--cert-name kptv`, чтобы nginx нашёл его.
2. Укажите `SERVER_HOST=<новый-домен>` в `.env`, затем `./kptv.sh restart`.
3. Перенастройте ТВ на новый адрес (ниже).

## Перенастройка ТВ на новый адрес

- **MSX (Tizen):** MSX → Настройки → Start Parameter →
  `https://<ваш-домен>/msx/start.json`.
- **Браузер ТВ:** один раз откройте `https://<ваш-домен>/client/?id=<device-id>`
  на каждом ТВ (id перечислены в панели — туннель:
  `ssh -L 8001:localhost:8001 user@<server>`, затем http://localhost:8001);
  дальше достаточно обычного URL `/client/`.

Шаг с `?id=` важен: клиент хранит id устройства в localStorage для каждого
origin, поэтому на новом адресе он иначе сгенерирует новый id и покажет экран
активации.

## Диагностика

| Симптом | Причина / решение |
|---|---|
| ТВ говорит, что сайт недоступен | DNS всё ещё указывает на старый IP — проверьте `nslookup <ваш-домен>` с любой машины |
| Предупреждение о сертификате в браузере | сертификат на старый домен — перевыпустите на имя, которое реально открывают ТВ |
| Экран активации на ТВ | ТВ потерял id устройства (новый origin) — используйте URL с `?id=<device-id>` один раз или просто активируйте заново |
