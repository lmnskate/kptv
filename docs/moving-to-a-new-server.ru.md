# Переезд на новый сервер

Переезд — это три вещи: поднять новый сервер, перенести базу (устройства и их
токены KinoPub живут в одном SQLite-файле), перенастроить ТВ на новый адрес.

Делайте это, пока старый сервер ещё работает — без свежей копии базы активации
не восстановить (см. последний раздел).

## 1. Свежий бэкап на старом сервере

```bash
./kptv.sh backup
```

Окажется в `backups/` на старом сервере. Файл содержит токены KinoPub всех
устройств — храните его как секрет.

## 2. Подготовьте новый сервер

1. Установите Docker и плагин Compose.
2. Скопируйте проект (свежий `git clone` подойдёт) и выполните:

   ```bash
   ./kptv.sh install
   ```

3. Заполните `.env`. Сначала определитесь с доменом (шаг 3) — `SERVER_HOST`
   должен быть точным именем, которое откроют ТВ.

## 3. Домен и сертификат

Развёртывание только по HTTPS, поэтому ТВ нужен домен, а не IP.

- **Тот же домен** (например, имя в DuckDNS, которое вы сохраняете): направьте
  его DNS-запись на IP нового сервера, затем выпустите сертификат на новом
  сервере точно как в README (Установка, шаг 3) и выполните `./kptv.sh start`.
- **Новый домен:** выпустите сертификат на новое имя, укажите его в
  `SERVER_HOST`, `./kptv.sh start`. Старый сервер может пока продолжать работать.

## 4. Перенесите базу

Откройте панель управления на старом сервере и нажмите **«Экспорт БД»**. Панель
только на loopback, поэтому сначала поднимите SSH-туннель со своего компьютера
и держите его открытым:

```bash
ssh -L 8001:localhost:8001 user@old-server
# затем откройте http://localhost:8001 в браузере
```

Сохраните скачанный файл (бэкап из шага 1 тоже подойдёт — это та же самая база).
Затем откройте панель нового сервера тем же способом
(`ssh -L 8001:localhost:8001 user@new-server`, http://localhost:8001) и нажмите
**«Импорт БД»**, выбрав экспортированный файл. Импорт полностью заменит базу
нового сервера — копия прежней сохранится рядом с основным файлом — и
работающий сервер подхватит новые устройства без рестарта.

Проверка: панель на новом сервере показывает все устройства.

## 5. Перенастройте ТВ на новый адрес

- **MSX (Tizen):** MSX → Настройки → Start Parameter →
  `https://<ваш-домен>/msx/start.json`.
- **Браузер ТВ:** один раз откройте `https://<ваш-домен>/client/?id=<device-id>`
  на каждом ТВ (id перечислены в панели — туннель открывается так же, как выше);
  дальше достаточно обычного URL `/client/`.

Шаг с `?id=` важен: клиент хранит id устройства в localStorage для каждого
origin, поэтому на новом адресе он иначе сгенерирует новый id и покажет экран
активации.

## 6. Выключите старый сервер

Когда все ТВ работают с новым адресом:

```bash
./kptv.sh stop
```

Файлы бэкапов пока подержите на всякий случай.

## Если старый сервер уже умер

Нет бэкапа — нет устройств: активации KinoPub без токенов из базы не
восстановить. Каждый ТВ активируется заново через экран с кодом и QR. Помните
про лимит ~5 устройств на аккаунт KinoPub; если упрётесь — удалите устройства
мертвого сервера в профиле KinoPub.
