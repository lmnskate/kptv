# Восстановление из бэкапа

Применяйте, когда сервер переустановлен, база повреждена или вы поднимаете
свежую копию. Всё — устройства, токены KinoPub, настройки, история — живёт в
одном SQLite-файле, поэтому восстановление сводится к одному импорту.

## Что понадобится

- Файл бэкапа, например `backups/kp-sqlite-20261104-110206.db`. Бэкапы делаются
  командой `./kptv.sh backup` (безопасно на работающем сервере).
- Чистая копия проекта на целевом сервере: `./kptv.sh install` уже выполнен,
  `.env` заполнен.

## Шаги

1. Скопируйте бэкап на машину, откуда сможете открыть панель управления
   (подойдёт любая с SSH-доступом к серверу):

   ```bash
   scp kp-sqlite-20261104-110206.db user@workstation:~/
   ```

2. Откройте панель. Её порт только на loopback, поэтому сначала поднимите
   SSH-туннель и держите его открытым:

   ```bash
   ssh -L 8001:localhost:8001 user@<сервер>
   # затем откройте http://localhost:8001 в браузере
   ```

3. Нажмите **«Импорт БД»** и выберите бэкап. Импорт полностью заменит базу
   сервера; копия прежней базы сохранится рядом с основным файлом. Рестарт стека
   не нужен.

4. Проверьте, что устройства появились в панели.

5. Откройте клиент на ТВ. Адрес тот же — всё просто работает, переактивация не
   нужна. Адрес новый — перенастройте ТВ один раз, см.
   [Смена IP или домена](changing-ip-or-domain.ru.md#перенастройка-тв-на-новый-адрес).

## Важно

- Импорт **полностью заменяет** текущую базу; всё, что было настроено на целевом
  сервере, пропадёт.
- Бэкап содержит токены KinoPub всех устройств — это секрет. `scp` для переноса
  подходит; мессенджеры и почта — нет.
- Если старый сервер уже недоступен и свежего бэкапа нет, каждому ТВ понадобится
  новая активация — токены без файла не восстановить.
